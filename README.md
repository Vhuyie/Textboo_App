# Textbook Hub

## Overview
Textbook Hub is an Android application developed in Kotlin that allows students to buy and sell second-hand textbooks.

## Features
- User Registration
- User Login
- Add Textbooks
- View Textbook Listings
- Search Textbooks
- View Seller Details
- Mark Books as Sold or Available
- Appointment Scheduling
- search functionality, searching for users
- profile
- Notifications

## Technologies Used
- Kotlin
- Android Studio
- RecyclerView
- SharedPreferences
- ConstraintLayout
- CardView
- In-memory storage

## How to Run
1. Open the project in Android Studio.
2. Allow Gradle to sync.
3. Run the application on an emulator or Android device.
